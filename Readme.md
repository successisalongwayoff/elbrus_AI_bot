# 🏔️ Elbrus Weather & ML Ascent Safety Bot

Telegram-бот на **aiogram 3** с встроенной системой машинного обучения (**Random Forest**) для прогнозирования погоды и автоматической оценки безопасности штурма вершины Эльбруса по 5 ключевым высотным локациям.

## 📌 Ключевой функционал

* **Многоточечный мониторинг:** Мониторинг 5 ключевых высотных точек Эльбруса (Поляна Азау, Станция Гарабаши, Приют 11, Седловина, Вершина Эльбруса).
* **Интеграция с Open-Meteo API:** Получение актуального прогноза погоды высокой точности (температура, ощущение, скорость и порывы ветра, влажность, осадки).
* **ML-Анализ безопасности (Две модели):**
  * **Прогноз на 1 час (Точность ~95%):** Оценка локальной стабильности погоды в ближайший час.
  * **Прогноз на 10 часов ("Окно штурма", Точность ~86%):** Анализ непрерывного 10-часового окна на отсутствие ураганных порывов ветра и критических температур.
* **Инженерные фичи (Feature Engineering):** Расчет лагов (`lag1`), трендов изменения ветра и температуры за последний час для учета динамики атмосферных фронтов.
* **Удобный UX/UI:** Интерактивная клавиатура в Telegram с цветовыми вердиктами безопасности (🟢 Безопасно / 🟡 Высокий риск / 🔴 Опасно).

```text

├── download_history.py     # Выкачивание архивных данных Open-Meteo (2023–2026)

├── predict.py              # Модуль инференса ML-моделей и форматирования текста
├── weather_api.py          # Асинхронный клиент для взаимодействия с Open-Meteo API
├── keyboards.py            # Inline-клавиатуры aiogram 3
├── handlers.py             # Обработчики команд и callback-запросов бота
├── main.py                 # Точка входа (запуск бота)
├── ascent_model_1h.pkl     # Обученная модель на 1 час
├── ascent_model_10h.pkl    # Обученная модель на 10-часовое окно штурма
└── requirements.txt        # Зависимости проекта
